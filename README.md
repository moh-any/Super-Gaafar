# Super Gaafar

Super Gaafar is a re-themed Super Mario-like platformer game coded in **C++** using the **Qt framework**. The game draws inspiration from the famous Egyptian series "Gaafar El-Omda" while retaining gameplay mechanics similar to the iconic Super Mario. Dive into a colorful world filled with parkour challenges, enemies, and power-ups as you guide Gaafar through exciting levels!

---

## Features

- **Sprite Sheets and Textures**: The game borrows the visual style of the classic Super Mario, utilizing similar sprite sheets and textures.
- **Re-Theme**: Inspired by the series *Gaafar El-Omda*, with modified sprites and themes. The theme can even be changed in the **main menu**.
- **Levels**: The game currently has **5 levels**, with more content planned for future expansion. 
- **Enemies**:
  - Goomba: A small brown mushroom creature.
  - Koopa: A yellow turtle-like enemy.
  - Spiny: A red spiked turtle enemy.
- **Power-Ups**:
  - **SpeedUp**: Collect yellow arrows to boost your speed.
  - **GiantUp**: Find the big yellow mushroom to grow giant and stomp enemies!
  - **JumpUp**: Equip the green frog suit to jump higher.
- **Coins**: Collect coins scattered across the levels to score higher.
- **Classic Gameplay**: Move from the leftmost part of the map to the right while performing parkour, collecting coins, and avoiding (or attacking) enemies.

---

## Controls

- **Arrow Keys**
  - **Left Arrow**: Move left.
  - **Right Arrow**: Move right.
- **Space/Up Arrow**: Jump. Use these to evade enemies, perform parkour, or reach higher platforms.

## How to Play

### Prerequisites
To run this game, you need to have **Qt** installed on your system.

### Instructions
1. Clone the repository to your local machine:
   ```bash
   git clone <repo_link>
   ```
2. Navigate to the directory where you've cloned the game.
3. Locate the `Super-Gaafar.pro` file.
4. Double-click on the `.pro` file to open it in Qt Creator.
5. **Build** and **Run** the project in Qt Creator.
